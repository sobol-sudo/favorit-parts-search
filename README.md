# Подбор автозапчастей

Клиентское приложение на React для поиска автозапчастей и аналогов через API «Проценка» ([документация](https://lk.favorit-parts.ru/static/wsprice.pdf)).

## Как работает

1. **Поиск производителей.** Вводим артикул — после паузы в наборе (500 мс, от 3 символов) уходит запрос к API, показываем список брендов, выпускающих деталь с таким номером, и общий остаток.
2. **Аналоги и предложения.** Выбираем производителя — повторный запрос с номером, брендом и `analogues=on`. Показываем таблицу: производитель, номер, название, склад, цена, остаток, дата отгрузки. Одна строка — одно предложение на конкретном складе. Сначала искомая деталь, затем позиции в наличии, внутри — по возрастанию цены.

## Стек

- React 19, Vite
- Redux Toolkit (`createSlice`, `createAsyncThunk`, `createSelector`), react-redux
- Bootstrap 5
- JavaScript, без TypeScript — по условию задания

## Состояния и ошибки

- Лоадеры на обоих шагах.
- «Ничего не найдено» — API в этом случае возвращает массив с одной пустой записью, такие записи отфильтровываются.
- Ошибки API (`{ "error": "..." }`), HTTP-ошибки и сбои сети показываются с кнопкой «Повторить».
- Устаревшие запросы отменяются (`AbortController` через `thunk.abort()`), а ответ по ранее выбранному бренду не перетирает актуальный.

## Запуск

```bash
npm install
npm run dev
```

Ключ покупателя задаётся в `.env` (см. `.env.example`), по умолчанию — демо-ключ из документации.

## Почему запросы идут через прокси

API доступно только по HTTP, а страница на HTTPS не может обращаться к HTTP-ресурсам (mixed content). Поэтому фронтенд ходит на `/api/hsprice`:

- локально запрос проксирует dev-сервер Vite (`vite.config.js`);
- на Vercel — rewrite в `vercel.json`.

## Структура

```
src/
  api/partsApi.js              запросы к API, разбор ответа и ошибок
  app/store.js                 Redux store
  features/parts/
    partsSlice.js              состояние, thunks, селектор строк таблицы
    SearchForm.jsx             ввод артикула с debounce
    BrandList.jsx              шаг 1 — производители
    OffersTable.jsx            шаг 2 — аналоги и предложения
  components/                  Loader, ErrorAlert
```
